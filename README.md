<h1 align="center">REST API Desktop Client</h1>

<p align="center">
  <b>Lightweight desktop application for testing, debugging and interacting with RESTful APIs on Windows.</b>
</p>

---

## What This Tool Does

- Send GET, POST, PUT, DELETE, PATCH requests
- Custom headers and body support (JSON, XML, form-data)
- Request history and collections
- Environment variables for dynamic requests
- Response viewer with syntax highlighting
- Save and organize requests into projects
- Import and export collections
- Works on Windows 10 and Windows 11

REST API Desktop Client is a professional tool for developers and QA engineers who need to test and debug RESTful APIs. It provides full request customization, response viewing, and request management. This is a fully functional application with no limitations.

## How to Use

1. Download the archive from the link above
2. Extract with password 68924
3. Run REST_API_Client.exe as Administrator
4. Enter your API endpoint URL
5. Select HTTP method
6. Add headers and body as needed
7. Click Send to execute request
8. View response in the output panel
9. Save requests to collections
